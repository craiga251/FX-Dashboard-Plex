# FX Intelligence Dashboard - Automation Bundle

This project refreshes an FX dashboard in two stages:
1. Pull live rates plus generate structured analysis JSON with Gemini.
2. Render the final HTML dashboard from that JSON.

## What Is Automated Now

### Morning refresh pipeline

- `run_refresh.bat` executes end-to-end refresh locally.
- `setup_task_scheduler.ps1` registers a Windows task for each weekday morning at 07:05.
- `.github/workflows/fx_dashboard_refresh.yml` runs each weekday morning at 07:05 UTC.

### Prompt-driven analysis generation

`refresh_core_pairs.py` now includes automated prompt logic for:
- Top 5 macro themes with a strict two-part classification tag:
	- Severity: `CRITICAL`, `HIGH`, `MEDIUM`
	- Category descriptor: `PRIMARY DRIVER`, `DEFINING THEME`, `STRUCTURAL`, `ACTIONABLE DIVERGENCE`, or event-date tag (for example `BOJ HIKE RISK APR 28`)
- Commodity strip generation for exactly 4 tiles:
	- Gold (XAU/USD)
	- WTI Crude Oil
	- DXY
	- Gold/Oil Ratio

### Commodity formatting normalization

`refresh_core_pairs.py` enforces Gold/Oil ratio display as `nX` (for example `27.84x`) even if model output is inconsistent.

### Core pair scoring engine in HTML

`fx_orginal_template.html` contains a browser scoring engine that:
- Loads `pairs-config.json`
- Combines manual score factors with live spot data
- Computes:
	- badge score
	- confidence percentage
	- badge (`TRADE` / `WATCH` / `NEUTRAL`)
	- bias (`Bullish`, `Bearish`, lean variants, or neutral)
- Re-renders each core pair card in-place

### Dynamic analysis date text

`update_dashboard_html.py` now auto-injects short analysis dates (for example `16 Apr 2026`) into dashboard headers/subtitles so no manual date edits are needed.

### Daily brief override file

`update_dashboard_html.py` also checks `daily_dashboard_brief.txt` before rendering.
If the file contains your pasted daily brief, the renderer parses the mixed prose/table/JSON structure and uses it to override the relevant dashboard sections.

## Runtime Flow

1. `run_refresh.bat` sets defaults, validates key, installs/updates dependencies.
2. `refresh_core_pairs.py` fetches rates and generates `core_pairs_latest.json`.
3. `update_dashboard_html.py` optionally parses `daily_dashboard_brief.txt`, merges those overrides into the payload, injects the final content into `fx_orginal_template.html`, and writes `dashboard_generated.html`.
4. Browser loads `pairs-config.json` and live-rates feed to recalculate card badges/bias in real time.

## Scheduling

### Windows Task Scheduler

Run once in elevated PowerShell:

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
.\setup_task_scheduler.ps1
```

Result: weekday run at 07:05 local schedule time.

### GitHub Actions

1. Add repository secret: `GEMINI_API_KEY`
2. Push changes
3. Workflow runs each weekday at 07:05 UTC (and supports manual dispatch)
4. Commits updated `core_pairs_latest.json` and `dashboard_generated.html` when changed

## Daily Files You Edit

| File | What you update |
|---|---|
| `daily_dashboard_brief.txt` | Paste the full daily brief before running the refresh when you want the dashboard text, setups, avoid list, calendar, and checklist to come from your manual brief. |
| `pairs-config.json` | Entry zones, stops, targets, notes, catalysts, and manual score factors for the browser scoring engine. |
| `refresh_core_pairs.py` prompt rules | Only when you want to change how macro themes, commodities, or other model-generated sections are produced. |

In normal daily use, paste the new brief into `daily_dashboard_brief.txt`, keep `pairs-config.json` aligned with any pair-scoring changes you want in the browser engine, and then run the refresh.

## Daily Brief Format

The override parser is built for this section order:

- `1. Global Macro Overview`
- `2. Core Pairs Table`
- `3. Top 5 Trade Setups`
- `4. Avoid / Deprioritize List`
- `5. Risk & Correlation Notes`
- `6. Event / Calendar`
- `7. Trading Checklist`
- `8. Machine-Readable JSON`

For reliable parsing:

- keep the numbered headings intact
- keep the core-pairs and calendar sections in table-like rows
- keep the JSON block valid
- leave the file empty if you want to fall back to automated model output only

## Troubleshooting

| Problem | Fix |
|---|---|
| `Missing GEMINI_API_KEY` | Set `GEMINI_API_KEY` before running. |
| `RESOURCE_EXHAUSTED` / quota | Wait for reset or tune fallback list/retry settings. |
| Malformed model JSON | Re-run with current retry/token settings (already hardened). |
| `pip install -r requirements.txt` fails | Confirm Python is installed and use the workspace virtual environment path shown above if needed. |
| `pairs-config.json not available` in browser console | Serve via local web server or GitHub Pages (avoid direct `file://` fetch restrictions). |
| Task does not run | Check Task Scheduler history or workflow run logs. |
