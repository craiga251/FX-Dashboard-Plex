# FX Intelligence Dashboard - Automation Bundle

This project refreshes an FX dashboard in two stages:
1. Pull live rates + generate structured analysis JSON with Gemini.
2. Render the final HTML dashboard from that JSON.

## Project files

### Source and config files

| File | Type | Purpose |
|---|---|---|
| `refresh_core_pairs.py` | Source | Fetches live FX rates, calls Gemini, writes `core_pairs_latest.json`. |
| `update_dashboard_html.py` | Source | Reads JSON and injects all dashboard sections into `fx_orginal_template.html`. |
| `fx_orginal_template.html` | Source | Canonical HTML template containing dashboard placeholders/tokens. |
| `run_refresh.bat` | Automation | Local runner for Windows. Installs deps, runs both Python scripts in sequence. |
| `setup_task_scheduler.ps1` | Automation | Registers a weekday Windows Task Scheduler job to call `run_refresh.bat`. |
| `.github/workflows/fx_dashboard_refresh.yml` | Automation | GitHub Actions scheduler that runs refresh/build and commits updated outputs. |
| `requirements.txt` | Dependency | Python package list required by the scripts. |
| `.env.example` | Config template | Environment variables for API key, model, retries, and paths. |
| `README.md` | Docs | Setup, operations, and troubleshooting guide. |

### Generated output files

| File | Generated by | Purpose |
|---|---|---|
| `core_pairs_latest.json` | `refresh_core_pairs.py` | Latest structured analysis payload used for rendering. |
| `dashboard_generated.html` | `update_dashboard_html.py` | Final dashboard artifact to open in a browser or publish. |

## Quick start (Windows)

1. Open a terminal in the project root.
2. Install dependencies.
3. Set your Gemini API key.
4. Run a manual refresh.

```powershell
pip install -r requirements.txt
setx GEMINI_API_KEY "your_key_here"
run_refresh.bat
```

For current PowerShell session only (without `setx`):

```powershell
$env:GEMINI_API_KEY = "your_key_here"
run_refresh.bat
```

Get your key from: https://aistudio.google.com/app/apikey

## Runtime flow

1. `run_refresh.bat` sets interpreter, validates key, installs dependencies.
2. `refresh_core_pairs.py` writes `core_pairs_latest.json`.
3. `update_dashboard_html.py` reads `core_pairs_latest.json` + `fx_orginal_template.html` and writes `dashboard_generated.html`.

## Scheduling options

### Windows Task Scheduler

Run once in elevated PowerShell:

```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
.\setup_task_scheduler.ps1
```

This registers `FX-Dashboard-Refresh` to run every 4 hours on weekdays.

### GitHub Actions

1. Push repo to GitHub.
2. Add secret `GEMINI_API_KEY` in repo settings.
3. Workflow `.github/workflows/fx_dashboard_refresh.yml` runs on weekday schedule.
4. Workflow commits `core_pairs_latest.json` and `dashboard_generated.html` when changed.

## Environment variables

Use `.env.example` as reference.

| Variable | Meaning |
|---|---|
| `GEMINI_API_KEY` | Gemini API key used for generation. |
| `GEMINI_MODEL` | Primary model (default `gemini-2.5-flash`). |
| `GEMINI_FALLBACK_MODELS` | Comma-separated fallback models. |
| `GEMINI_MAX_RETRIES` | Retries per model before fallback/exit. |
| `GEMINI_RETRY_BACKOFF_SECONDS` | Exponential backoff base delay in seconds. |
| `GEMINI_MAX_OUTPUT_TOKENS` | Output token cap for model response. |
| `ANALYSIS_TIMEFRAME` | Prompt timeframe hint used by analysis generation. |
| `OUTPUT_JSON` | Output path for generated JSON. |
| `CORE_JSON` | Input JSON path for HTML renderer. |
| `DASHBOARD_TEMPLATE` | Template file path used by renderer. |
| `DASHBOARD_OUTPUT` | Final rendered HTML path. |

## Troubleshooting

| Problem | Fix |
|---|---|
| `Missing GEMINI_API_KEY` | Set `GEMINI_API_KEY` before running. |
| `400 Bad Request` from model call | Verify key + model compatibility (Gemini key with Gemini model). |
| `RESOURCE_EXHAUSTED` / quota error | Wait for quota reset or add stronger fallback model list. |
| JSON parse failures | Re-run; check retry settings and model stability. |
| `refresh_core_pairs.py` not found | Run from project root where scripts exist. |
| Task Scheduler job not firing | Check Task Scheduler history and `refresh.log` output path. |
